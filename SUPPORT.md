# Support

RE:FRAME is **pre-release**. There is no production service, no releases, and **no SLA at this stage**.

## How to get help

| Type of request | Where |
|-----------------|-------|
| Bug reports | [Bug report](../../issues/new?template=bug_report.yml) issue template |
| Feature ideas | [Feature request](../../issues/new?template=feature_request.yml) issue template |
| Questions about contributing or direction | [Open an issue](../../issues/new) |
| Security vulnerabilities | Private reporting per [SECURITY.md](SECURITY.md) — never a public issue |
| Conduct concerns | Private contact per [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## What to expect

- Responses are best-effort and provided by maintainers in their available time.
- Please search existing issues before opening a new one, and complete the issue templates fully.
- This project does not provide clinical, medical, or mental-health advice. It is a wellness software project; if you are in crisis, contact your local emergency number or a crisis line in your country.

## Documentation

The documentation index lives at [docs/README.md](docs/README.md). Documentation beyond the index is planned and will land alongside the corresponding implementation stages.
